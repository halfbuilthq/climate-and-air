# Publishing and HACS Default checklist

Repository: `halfbuilthq/climate-and-air`

1. Confirm CI and HACS validation pass on `main` without ignored checks.
2. Publish a full GitHub release containing `climate-air-card.js`.
3. Install the release as a custom HACS **Dashboard** repository and verify it.
4. Add `halfbuilthq/climate-and-air` alphabetically to `plugin` in a fresh
   branch of a personal fork of `hacs/default`.
5. Complete the HACS pull-request template accurately and allow maintainer edits.
