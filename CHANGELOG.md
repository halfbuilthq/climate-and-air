# Changelog

All notable changes to this project are documented here. The project follows
Semantic Versioning.

## [Unreleased]

## [0.1.4] - 2026-11-01

### Fixed

- Keep long air-quality descriptions inside their sensor tiles and wrap VOC text.
- Stack compact mode and fan controls, keep humidity content readable, and fit target controls and the humidity ring in narrow cards.

## [0.1.3] - 2026-09-02

### Changed

- Clear chart inspection when a touch gesture is cancelled by scrolling.
- Added regression coverage for Home Assistant's current and legacy card
  background theme variables.

## [0.1.2] - 2026-09-02

### Added

- HACS Default catalogue information and publishing guidance.
- Repository security policy and dependency maintenance configuration.

## [0.1.1] - 2026-07-29

- Initial public release of the Climate & Air Card.
